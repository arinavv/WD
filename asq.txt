1. Свойство position
Значения и их влияние:
- static (по умолчанию) - элемент следует обычному потоку документа
- relative - позиционируется относительно своего нормального положения, можно сдвигать с помощью top/right/bottom/left
- absolute - вырывается из потока, позиционируется относительно ближайшего позиционированного предка
- fixed - фиксируется относительно окна браузера, не скроллится
- sticky - ведет себя как relative, пока не достигнет заданного порога, затем фиксируется
2. Свойство display
- block - занимает всю ширину, начинается с новой строки (div, p, h1)
- inline - занимает только необходимую ширину, не начинается с новой строки (span, a, strong)
- inline-block - как inline, но можно задавать ширину/высоту и margin/padding (img, button)
- none - полностью удаляет элемент из потока, не занимает места
Примеры:
css
.block { display: block; } /* Для структуры страницы */
.inline { display: inline; } /* Для текстовых элементов */
.inline-block { display: inline-block; } /* Для кнопок, иконок */
.hidden { display: none; } /* Скрыть элемент */
3. Блочная модель CSS
Состоит из:
1. Content - содержимое элемента
2. Padding - внутренний отступ
3. Border - граница
4. Margin - внешний отступ
Основные свойства:
- `width`, `height` - размеры контента
- `padding` - внутренние отступы
- `border` - границы
- `margin` - внешние отступы
- `box-sizing` - контролирует, что включается в ширину/высоту
4. flex-direction
Определяет направление главной оси флекс-контейнера:
- row (по умолчанию) - слева направо
- row-reverse - справа налево
- column - сверху вниз
- column-reverse - снизу вверх
css
.container {
  display: flex;
  flex-direction: row; /* элементы в строку */
}
5. align-items и justify-content
justify-content - выравнивание по главной оси (горизонтально при row):
- `flex-start` - к началу
- `flex-end` - к концу
- `center` - по центру
- `space-between` - равномерно с отступами между
- `space-around` - равномерно с отступами вокруг
align-items - выравнивание по поперечной оси (вертикально при row):
- `stretch` (по умолчанию) - растянуть
- `flex-start` - к верху
- `flex-end` - к низу
- `center` - по центру
- `baseline` - по базовой линии текста
css
.container {
  display: flex;
  justify-content: center; /* по горизонтали */
  align-items: center;     /* по вертикали */
}
6. Красивое применение flexbox
Пример - карточки товаров в интернет-магазине:
css
.products-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
  justify-content: center;
}
.product-card {
  flex: 1 1 300px; /* гибкость, мин. ширина 300px */
  max-width: 400px;
}
Преимущества: автоматическая адаптация к разным экранам, равномерное распределение, контроль выравнивания.
Реальный пример: Макет навигационной панели с логотипом слева, меню по центру и кнопками справа:
css
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
